# Task Management System

## Overview
The Task Management System is a full-stack web application designed to help users efficiently create, organize, manage, and track their daily tasks. It provides a user-friendly interface with secure authentication and task management functionalities.

The application is developed using **Spring Boot** for the backend, **React.js** for the frontend, and **MySQL** for database management. JWT-based authentication ensures secure access to user-specific tasks.

## Features
- User Registration and Login
- JWT-Based Authentication and Authorization
- Create, View, Update, and Delete Tasks (CRUD Operations)
- Task Status Management
- Task Priority Management
- Due Date Management
- User-Specific Task Management
- Secure REST API Integration
- Responsive and Professional User Interface
- Backend Validation and Exception Handling

## Architecture
The application follows a client-server architecture:

- React.js handles the user interface.
- Spring Boot manages business logic and REST APIs.
- Spring Security and JWT handle authentication and authorization.
- MySQL stores user and task information.
